# Project conduct

We want participation in this project to be respectful, constructive, and safe.

## Expected behavior

- Treat other participants with respect.
- Discuss ideas and code without personal attacks.
- Give specific, actionable feedback.
- Respect privacy and do not publish another person's private information.
- Avoid harassment, discrimination, threats, or disruptive behavior.

## Enforcement

Project maintainers may edit or remove comments, issues, pull requests, or other contributions that violate this policy. Repeated or serious violations may result in a temporary or permanent participation restriction.

Report conduct concerns privately to the project maintainers through an available private repository contact channel. Do not include sensitive personal information in a public issue.
