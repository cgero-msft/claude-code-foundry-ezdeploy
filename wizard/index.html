Deploy Claude Code with Microsoft Foundry

Work through the deployment choices, then download a populated launcher for Azure Cloud Shell. The generated files use Microsoft Entra authentication and contain no API keys.

Select exact model versions

No billable model deployment is selected by default. Choose one or more catalog versions explicitly; recommended Sonnet, Haiku, and Opus starting points remain badged below. Checkboxes allow multiple versions, including multiple versions from the same Claude family.

Version pinning and quota

Each selection becomes a distinct Global Standard deployment pinned with NoAutoUpgrade. The engine validates the exact version, version-specific quota pool, and requested capacity before deployment.

Confirm Claude Code defaults

Claude Code routes Sonnet, Haiku, and Opus aliases to deployment names. When more than one selected version belongs to the same family, choose exactly one family default.

At least one usable default is required

Every selected family must have one selected deployment mapped as its default. Families you do not deploy are omitted from the generated workstation configuration.
